Load from data folder

Choose a subfolder of DATA_DIR that already contains extracted TecDoc files named NNN.xxxx (e.g. 001.0001 → table t001). By default each line is a fixed-width record (field sizes from your table columns: varchar(n), integer, numeric(p)). Set ROW_PARSE_MODE=delimiter to use FIELD_DELIMITER instead. No header row. Data is copied into tecdoc_gheorghe. Loading first deletes existing rows for that supplier (folder name = DLNr) from every table that has a dlnr column, then imports the files. Check Skip purge to skip the delete and instead insert only into tables that have no existing rows for this supplier. Each step is logged in the job (progress.steps) and in the server process logs.
