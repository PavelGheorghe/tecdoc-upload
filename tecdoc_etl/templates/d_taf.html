Load all suppliers (D_TAF)

Under DATA_DIR / {{ d_taf_subdir }} (D_TAF_SUBDIR), picks each supplier in ascending id order from *.7z archives (e.g. 0001.7z) and/or extracted folders. Archives are unpacked to DATA_DIR/extract/<id>/ before load. If both 0001.7z and 0001/ exist, the zip is used. Then: purge that dlnr, import files (no global truncate), unless truncate_first is enabled for a full-refresh run.
